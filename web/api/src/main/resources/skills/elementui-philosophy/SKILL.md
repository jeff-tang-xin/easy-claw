# Element UI / Element Plus 设计理念

本 Skill 提供 Element UI（Vue 生态最流行的中后台组件库）的设计语言，用于指导
UI 实现与样式审查。Element UI 与 Element Plus 视觉规范一致（Plus 为 Vue3 版）。

## 子规则索引

| 文件 | 覆盖范围 |
|------|----------|
| `tokens.md` | 设计令牌完整速查：色彩/字体/边框/填充/阴影/动效/层级/断点 |
| `components.md` | 组件规范：按钮/输入/表格/弹窗/消息反馈等 16 类组件的尺寸与状态 |

| `do-dont.md` | 正反例对照清单：八大维度的 ✅/❌，可直接当 UI 审查清单用 |

## 设计四原则（Why）

1. **一致性（Consistency）**
   - 与现实一致：沿用现实世界的隐喻与习惯（如红色=危险）
   - 与项目内一致：同样的交互、同样的样式，全站统一
2. **反馈（Feedback）**
   - 让用户清楚感知：操作结果、当前状态、系统在做什么
   - 页面/控件有 hover、active、disabled、loading 全套状态
3. **效率（Efficiency）**
   - 简化操作流程：默认值、快捷方式、表单校验前置
   - 界面清晰直白，不让用户思考
4. **可控（Controllability）**
   - 用户是发起者也是掌控者：可撤销、可中断、可自定义
   - 危险操作有二次确认；导航清晰可回退

## 气质定位（与 AntD 的差异）

| 维度 | Element | Ant Design |
|------|---------|------------|
| 气质 | 亲和、明快、轻量 | 专业、克制、企业级 |
| 主色 | `#409eff`（更柔和的天蓝） | `#1677ff`（更纯的蓝） |
| 圆角 | 4px（方正利落） | 6px（圆润） |
| 控件高度 | 40px（default，更舒展） | 32px（紧凑） |
| 文字色 | 实色四级（#303133 系） | 黑色透明度四级 |
| 适用 | 中后台管理、工具型产品 | 复杂企业应用、数据密集 |

## 快速参考（速查版，完整见 tokens.md）

### 色彩
- 主色 `#409eff`；hover `#66b1ff`、active `#3a8ee6`
- 文字四级：`#303133` 主要 / `#606266` 常规 / `#909399` 次要 / `#c0c4cc` 占位
- 功能色：成功 `#67c23a`、警告 `#e6a23c`、危险 `#f56c6c`、信息 `#909399`
- 边框四级：`#dcdfe6` / `#e4e7ed` / `#ebeef5` / `#f2f6fc`（由深到浅）
- 填充：页面底 `#f0f2f5`、hover 填充 `#f5f7fa`、禁用底 `#f5f7fa`

### 字体与尺寸
- 基准 14px、行高 1.5；标题 20/18/16
- 控件高度三档：40（default）/ 32（small）/ 24（mini）

### 形状与阴影
- 圆角 4px（小圆角，方正利落）
- 阴影：`0 2px 4px rgba(0,0,0,0.12), 0 0 6px rgba(0,0,0,0.04)`（base）

### 动效
- 0.3s `ease`；fade/zoom/slide 体系；动效轻快不拖沓

## 在 Easy-Claw 项目中的应用

- 若整体切 Element 风格：`--accent: #409eff`、`--accent-dark: #3a8ee6`、控件圆角收敛 4–6px
- 文字四级可直接映射：`--text: #303133`、`--text-secondary: #606266`、`--text-tertiary: #909399`
- 与 `frontend-quality` skill 配合：本 skill 定「长什么样」，frontend-quality 定「质量红线」
- 注意：`#909399` 在白底对比度 3.0:1，仅限辅助信息；正文必须 `#606266` 以上（AA 红线）

### UI 审查清单（快速版，完整见 do-dont.md）

1. primary 按钮是否唯一？删除是否有 popconfirm/MessageBox 确认？
2. 文字是否按四级实色取用？正文 ≥ #606266（对比度达标）？
3. 边框是否按四级取用（控件/卡片/表格线分层）？
4. 空态/加载态/错误态三态是否齐全？
5. 键盘是否可达？弹窗关闭是否 resetFields？
6. 反馈是否分级（Message/Notification/MessageBox 用对场景）？
