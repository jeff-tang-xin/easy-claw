# Ant Design 典型页面模式

> 企业应用 80% 的页面可归为以下模式。做新页面前先对号入座，不要发明新布局。

## 1. 应用骨架（ProLayout 三种布局）

| 布局 | 适用 | 结构 |
|------|------|------|
| 侧边菜单（side） | 菜单项多、层级深（默认） | 深色侧栏 208px + 顶栏 64px + 内容区 |
| 顶部菜单（top） | 菜单项 ≤ 7 个、一级扁平 | 通栏顶栏 + 内容区 |
| 混合（mix） | 菜单多且强调品牌 | 顶部一级 + 侧边二级 |

- 内容区：`#f5f5f5` 底、padding 24px、面包屑在内容区顶部
- 侧栏折叠：收至 80px 只留图标，hover 浮出子菜单

## 2. 查询列表页（最高频模式）

```
PageContainer
├─ 查询表单区（Card，可展开/收起）
│   常用字段平铺 + 「展开」收起低频字段 + 查询/重置按钮右对齐
├─ 工具栏（表格上方）
│   左：新建按钮（primary）+ 批量操作（选中后出现）
│   右：刷新 / 列设置 / 全屏（图标按钮组）
├─ 表格（Card 内）
│   操作列固定右侧，≤ 3 个动作，超出收进「更多」下拉
└─ 分页（表格右下）
    总条数 + 每页条数 + 快速跳转
```

- 查询条件 ≤ 8 个；日期范围用 RangePicker；状态用 Select 不用 Radio
- 批量操作：勾选后表格顶部出现提示条（已选 N 项 + 批量按钮）
- 删除等危险批量操作：Modal.confirm 二次确认，成功后 Message + 刷新

## 3. 表单页

| 形态 | 适用 | 要点 |
|------|------|------|
| 标准表单 | 字段 ≤ 20 | 分组 Card 或 Divider 分节；底部操作条（提交/重置） |
| 分步表单（Steps） | 流程 > 3 步或字段 > 25 | 步骤条 + 每步独立校验 + 上一步/下一步 |
| 分组表单（Group） | 字段多但流程单一 | 锚点导航 + 分组卡片 |
| 弹窗表单 | 轻量编辑（≤ 8 字段） | Modal 宽 520–640；底部按钮在弹窗内 |

- label 右对齐（horizontal）；必填红星；字段说明用 Tooltip/extra
- 提交：按钮 loading 防重复；成功 Message + 返回列表或继续编辑
- 长表单：底部操作条 sticky（滚动时可见）

## 4. 详情页

```
PageContainer（标题 + 状态标签 + 操作按钮组）
├─ Descriptions 描述列表（3 列，bordered）
├─ Tab 切换关联信息（Tabs）
│   ├─ 关联表格 A
│   └─ 关联表格 B
└─ 时间线/日志（Timeline，可选）
```

- 主键/编号等关键信息放 Descriptions 首行；状态用 Tag（语义色）
- 操作按钮：主操作 primary 在右上，次要收进 Dropdown「更多」

## 5. Dashboard / 数据看板

- 统计卡片行：Statistic（数值大字 + 趋势箭头）× 4，Card 等高
- 图表区：Card 包裹图表（标题 + extra 时间筛选）
- 图表库不内置——配 @ant-design/charts 或 ECharts；配色从主色色阶取
- 卡片间距 16px；数值字体 tabular-nums

## 6. 结果页（Result）与异常页

- Result：成功（绿勾）/警告/失败（红叉）大图标 + 主文案 + 补充文案 + 操作按钮组
- 异常页 403/404/500：统一插画 + 文案 + 「返回首页」按钮
- 表单提交成功后跳 Result 页（重要流程）或 Message（轻量操作）

## 7. 设置页

- 左右分栏：左侧菜单（itemInverted 或纯文字列表，宽 200px）+ 右侧表单
- 移动端退化为顶部 Tabs
- 每组设置独立保存或统一底部保存条（二选一，全站统一）

## 8. 登录页

- 居中卡片（宽 400 左右）或左右分栏（左品牌区/右表单）
- 字段：账号/密码/验证码 + 记住我 + 登录按钮（block primary）
- 第三方登录：Divider「其他登录方式」+ 图标按钮组
- 错误反馈：表单校验（格式）+ Alert（账号密码错误，可关闭）

## 9. 加载与空的层级策略

| 场景 | 方案 |
|------|------|
| 首屏/整页 | Skeleton 骨架屏（结构可预知时）或 Spin 居中 |
| 表格刷新 | 表格自带 loading 遮罩（不遮全页） |
| 按钮动作 | 按钮 loading 态 |
| 无数据 | Empty + 行动按钮（如「新建」） |
| 搜索无结果 | Empty + 「清空筛选条件」 |
