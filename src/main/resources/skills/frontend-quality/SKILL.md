# 前端质量标准

本 Skill 为前端代码提供全面的质量规范。目录下包含多个规则文件，按需查阅。

## 快速参考

### 组件设计
- 单一职责：每个组件只做一件事
- Props 扁平化：不超过 5 个 props，超过考虑拆分
- 受控组件：数据从父级流入，通过回调流出

### 性能红线
- 渲染阻塞主线程超过 50ms
- 无限列表不做虚拟滚动
- 首屏 bundle > 300KB（gzip）

### 无障碍底线
- 颜色对比度 ≥ 4.5:1
- 所有交互元素可键盘访问（Tab 可达）
- 图片有 alt，装饰性图片 alt=""
